DRIVEASE — QUICK START

This is a fresh standalone project folder. You do NOT need to copy files from your old DrivEase folder.

1. Install Node.js (LTS) and MySQL Server if they are not already installed.
2. Open the server folder.
3. Copy server\.env.example and rename the copy to .env (so the final path is server\.env).
4. Open server\.env and enter your own MySQL connection values:
   PORT=3001
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_USER=your_mysql_username
   DB_PASSWORD=your_mysql_password
   DB_NAME=drivease_db
   CLOUDINARY_* values are only needed for cloud image uploads.
   SESSION_SECRET=any-long-random-secret
5. In MySQL, create the database named drivease_db and run database\schema.sql.
   Then run the SQL migration files in database\migrations in filename order.
6. Double-click START-DRIVEASE.bat.
7. Open http://localhost:8444/ if it does not open automatically.

QUICK CHECK
- Backend: http://localhost:3001/api/health
- Frontend: http://localhost:8444/
- Backend date tests: open a terminal in server and run `node test-booking-date.js`.

IMPORTANT
- Keep both terminal windows open while using the app.
- This package includes the booking date validation fix and the protected vehicle image upload route.
- The app still requires a working MySQL database and valid server/.env settings. Do not share your .env file or its contents.
